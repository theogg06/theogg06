Widget Feedback — Prezentare vizuală

Propunere UI 2026

Widget de colectare feedback vizibil pe fiecare pagină a site-ului BNR. Fixat în bara de jos, non-intruziv, cu flux în 4 pași (întrebare inițială → motive → text liber → confirmare). Datele sunt trimise la un endpoint configurat și nu mai apare timp de 30 de zile după ce utilizatorul oferă un răspuns.

Caracteristici tehnice
📌

Fixat în josul paginii

Position: fixed — vizibil indiferent de scroll, pe orice pagină.

🔁

Cooldown 30 zile

După feedback, widget-ul dispare pentru 30 de zile (localStorage).

📡

API endpoint

Trimite datele via fetch() la orice URL backend configurat.

♿

Accesibil WCAG 2.1

ARIA labels, focus vizibil, navigare completă cu tastatura.

📱

Responsive

Se adaptează pe orice rezoluție, inclusiv mobile.

⚡

Zero dependențe

Vanilla JS + CSS pur — fără jQuery, fără framework-uri.

✏️

Text liber

Opțiunea „Altceva" deschide un câmp pentru detalii suplimentare.

🎨

Identitate BNR

Albastru #003087 + auriu #FFD700 — conform brand BNR.

Cod de integrare
Adaugă înainte de </body> pe fiecare pagină
<!-- 1. Stiluri widget -->
<link rel="stylesheet" href="/assets/feedback-widget.css" />

<!-- 2. Configurare (opțional) -->
<script>
  window.BNR_FEEDBACK_CONFIG = {
    endpoint:     '/api/feedback',  // URL-ul backend-ului
    cooldownDays: 30,               // nu mai arăta 30 de zile
    showDelayMs:  1500,             // apare după 1.5s
  };
</script>

<!-- 3. Script widget -->
<script src="/assets/feedback-widget.js"></script>
