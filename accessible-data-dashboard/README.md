# Accessible Data Dashboard (B2B / Fintech)

Portfolio project showing accessible data visualisation for analysts, finance managers and compliance officers, built on real ECB and Eurostat data.

**Status:** Phase 0 (research kit) complete · Phase 1 (design) awaiting approval — see [`design/SPEC.md`](design/SPEC.md) and the [Figma file](https://www.figma.com/design/rKEwC8areZnXnjiouJh22w).

| Folder | Contents |
|---|---|
| [`research/`](research/) | Desk research, interview kit, consent, templates, proto-personas and JTBD (**hypotheses**) |
| [`design/`](design/) | Phase 1 spec and Figma screenshots |
| [`packages/tokens/`](packages/tokens/) | Placeholder design tokens (light / dark / high contrast) |
| [`scripts/check-contrast.mjs`](scripts/check-contrast.mjs) | WCAG contrast check for all token pairs |
| [`DECISIONS.md`](DECISIONS.md) | Rationale for every non-obvious choice |

The full README (architecture, data sources and licences, how to run, test and deploy) is added in Phase 5.
