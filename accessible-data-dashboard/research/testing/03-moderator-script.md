# Moderator script

**Before the session:** reset the prototype (footer → Prototype controls → Reset prototype). Open `06-observation-sheet.md` for this participant. Have each task link from `02-task-scenarios.md` ready to paste. Check that consent has been received.

## Welcome (3 min)
> Thanks for joining. Today I'll ask you to try an early prototype of a data dashboard and think out loud while you use it. **We're testing the prototype, not you.** If something is confusing, that's exactly what we need to find out. Nothing you do can be wrong, and you won't hurt my feelings.
>
> Some of the data is real, from the ECB and Eurostat. Some is made up so we can test unusual situations, and that's labelled "Synthetic data" on screen. Please don't rely on any of it for real decisions.
>
> We'll take about [60/75] minutes. You can take a break or stop at any time.
>
> [If consented] I'll start the recording now. Can you confirm you're OK with that? *(Wait.)*

## Setup check (2 min)
> Which browser are you using today? Do you use any assistive technology or settings, such as a screen reader, magnification, zoom, high contrast or voice control? *(Record. Don't ask why.)* Please keep them exactly as you normally have them.

AT sessions: ask them to share screen **and system audio**. Agree a signal for "please repeat that" and for a break.

## Think aloud (3 min)
Read `04-think-aloud-instructions.md` and do the practice task.

## Tasks (≈ 40 min)
For each task:
1. Send or paste the task link. Ask: "Tell me when the page has loaded."
2. Read the task **verbatim**. Offer to paste it into the chat.
3. Start timing when you finish reading.
4. Stay quiet. Neutral prompts only:
   - "What are you looking for?"
   - "What do you expect to happen?"
   - "What's going through your mind?"
5. **Don't** name or point to UI elements. If they're stuck for more than 3 minutes: "Is there anything else you'd try?" After 5 minutes: "Let's move on. That's really helpful to know."
6. When they state a decision, stop timing. Ask the **SEQ**:
   > "On a scale from 1 to 7, where 1 is very difficult and 7 is very easy, how easy or difficult was that?"
7. Task probe (from `02`), then: "Was there anything that made you trust or doubt the numbers?"

Never fix things for the participant. If the prototype breaks, note it and go to the next task (severity 4).

## SUS (5 min)
> "Last part: ten short statements about the dashboard as a whole. For each one, tell me how much you agree, from 1, strongly disagree, to 5, strongly agree."

Use `07-sus-questionnaire.md`. Read the statements aloud for screen reader users, or send the accessible form; whichever they prefer.

## Debrief (5 min)
1. What was the most useful part? The most frustrating?
2. Was anything missing that you'd need before making a real decision?
3. *(AT users)* How did this compare with other dashboards or charts you use?
4. Anything else you'd like to tell me?

> "Thank you, this was really valuable. [Compensation details.] If you want your data withdrawn, email [contact] with your participant ID."

Stop recording. Reset the prototype. Write the debrief section of the observation sheet within 15 minutes.
