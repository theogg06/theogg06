# Accessibility statement: Euro Area Monitor (prototype)

*Last reviewed: 1 November 2026 · Applies to the prototype at `https://theogg06.github.io/theogg06/` and builds from this repository.*

This is a portfolio prototype, not a production service. We want it to be usable by as many people as possible, including people who use screen readers, screen magnifiers, voice control, keyboard-only navigation, high contrast or forced-colors modes, and people with cognitive disabilities.

## Conformance target

**WCAG 2.2 Level AA.** Status: **partially conformant, not yet verified by people with disabilities.** The automated checks below pass, but automated tools catch only some accessibility problems. Manual testing with assistive technology and usability sessions with disabled participants are planned, and their kit is in `research/testing/`. Until those are done we don't claim full conformance.

## What we did

- Information is never conveyed by colour alone. Chart series use colour, line dash, marker shape and direct labels; areas and bars use patterns; status badges use icons and text.
- Every chart has a semantic table alternative, a generated text summary that always states missing data, keyboard navigation through data points, and tooltips that appear on focus, can be hovered and can be dismissed with Escape.
- Light, dark and high-contrast themes. In Windows forced-colors mode, charts follow the system colours.
- The layout reflows at 320 CSS px and at 200% and 400% zoom. Only data tables scroll horizontally, inside their own labelled region.
- Status messages (filters applied, view saved, loading finished, errors) are announced through live regions.
- Motion is reduced when the operating system asks for it.
- No time limits, no analytics, no cookies.

## Known limitations

1. **Not yet tested with screen readers by hand.** The single-key chart shortcuts (S, T) may be captured by a screen reader's browse-mode quick keys. Arrow-key navigation and the table view work without them.
2. **Sonification** ("Play as sound", drill-down only) is experimental. It has no alternative audio description of the full series beyond the text summary.
3. In **forced-colors mode**, the heatmap's colour bins disappear by design. Every cell still prints its value, and the table view is available.
4. **Highcharts' own screen-reader text** ("End of interactive chart", axis descriptions) is generated by the library. Its wording isn't fully under our control.
5. **Synthetic data:** simulated states replace real values with generated ones. They're always labelled "Synthetic data", but a user could still misread them if they skip the label.
6. **Language:** English only. Numbers use the en-GB format (decimal point).
